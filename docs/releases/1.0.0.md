# CppBridgeJ 1.0.0

Stable primitive scalar and primitive array bindings for Java and C++ through the Foreign Function & Memory API.

- Native libraries are packaged in application JARs and loaded automatically for the current platform.
- Repeated array arguments preserve aliasing and combine copy directions correctly.
- Default interface methods, invalid signatures, missing symbols, and native array lifecycle failures have consistent handling.
- The Maven plugin supports include directories, linker arguments, compiler timeouts, and packaged consumer builds.
- Maven Wrapper, a complete quickstart, and Linux, macOS, Windows, and JDK 26 checks are included.

## Downloads

Use JDK 22 or newer. Platform ZIPs include the example, benchmark runner, and native libraries; follow their README to run without a compiler. The platform and architecture are part of each filename.

`cppbridgej-1.0.0-maven.zip` contains the parent POM, runtime, Maven plugin, sources, and JavaDoc in local repository layout. Extract it into your Maven local repository before following [the quickstart](https://github.com/alman790/cppbridgej/blob/v1.0.0/docs/QUICKSTART.md). Building your own native code still requires a C++ compiler.

`cppbridgej-1.0.0-source.zip` contains the release source tree. `SHA256SUMS` covers every attached artifact; on Linux run `sha256sum -c SHA256SUMS` after downloading all files.

Maven Central publication is pending: this release uses GitHub distribution. Strings, structs, callbacks, and explicit library unloading are outside the 1.0 API. Native declarations must match the documented ABI.
