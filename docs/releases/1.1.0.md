# CppBridgeJ 1.1.0

Bindings now include naturally aligned structs, nested records, fixed inline arrays, owned struct buffers, UTF-8 strings, explicit enums, pointers, callbacks, and all Java primitive widths.

`@CppStatus` and the bundled `cppbridge.hpp` translate caught C++ exceptions into Java failures. `NativeHandle` manages opaque objects with deterministic destruction. The runnable example includes a C++ class using `std::string`, `std::vector`, a templated method and `std::function`.

`CppBridge.downcall` accepts explicit FFM layouts for unions and C variadic functions. Existing 1.0 scalar and array bindings remain supported.

The release includes Linux x86_64, macOS aarch64, and Windows x86_64 distributions, a Maven repository ZIP, sources, JavaDoc, and SHA256 checksums. Use JDK 22 or newer. Extract the Maven ZIP into your local repository and follow [the quickstart](https://github.com/alman790/cppbridgej/blob/v1.1.0/docs/QUICKSTART.md).

See [rich types](https://github.com/alman790/cppbridgej/blob/v1.1.0/docs/RICH_TYPES.md) for declarations and lifetimes. C++ object layouts, templates, STL and exceptions require C-compatible wrappers; arbitrary header binding generation is not included. Maven Central publication is still pending.
