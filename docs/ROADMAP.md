# Roadmap

## Delivered in 1.0.0

- Stable primitive scalar and array API with diagnostics and managed native arrays.
- Native library packaging and platform-aware loading from JARs.
- Maven compiler configuration, timeouts, and packaged consumer verification.
- Runnable platform distributions and a Maven repository bundle.

## Delivered in 1.1.0

- Struct values, nested layouts, inline arrays and owned struct buffers.
- UTF-8 strings, int32 enums, pointers, callbacks and opaque object ownership.
- A C++ exception guard and Java status translation.
- A C++ class/STL example and explicit FFM access for unions and C varargs.

## Distribution follow-up

- Complete Maven Central namespace access, credentials, signing, and publication.

## 1.x

- Generated binding metadata files for Java interfaces.
- Header-based generation of C-compatible wrappers and layout assertions.
- Java Vector API comparison benchmarks.
- Improved type-mapping errors.
- More platform-specific resolver tests.

## Later

- Gradle plugin.
- WASM backend.
- Spring Boot integration.
- Generated stubs for larger APIs.
